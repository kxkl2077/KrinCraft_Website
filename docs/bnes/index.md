# 🎮 街机使用指南

Stalir 的街机功能可以在游戏内运行 NES 游戏。购买并安装游戏机后，你可以插入卡带游玩超级玛丽、坦克大战等经典游戏。

## 创建游戏机

游戏机有两种尺寸：

| 指令 | 屏幕尺寸 | 说明 |
| --- | --- | --- |
| `/bnes create <实例名>` | 4 张地图 | 默认的四格大屏游戏机 |
| `/bnes create <实例名> min` | 1 张地图 | 适合空间较小的单格游戏机 |

创建一台游戏机需要 **1000 K 币**。实例名由你自行设置，后续取回地图、重命名或关闭游戏机时都会用到，请妥善记住。

## 安装与游玩

### 第一步：安装游戏机

默认游戏机的安装方法如下：

1. 执行创建指令后，背包中会获得 4 张地图；
2. 在墙面上放置 4 个物品展示框，并按下图排列；

![四格游戏机的安装示意图](/images/bnes.png)

3. 将 4 张地图分别放入对应的展示框；
4. 在屏幕前放置 2 个楼梯作为座位。

使用 `min` 参数创建的游戏机只会获得 1 张地图，放入单个物品展示框即可。

::: tip 地图丢失或安装错误
地图丢失、损坏或四格屏幕显示顺序异常时，请记录游戏机的实例名并联系管理员处理。
:::

### 第二步：购买游戏卡带

1. 执行 `/bnes menu` 打开卡带菜单；
2. 选择想玩的游戏，每张卡带需要 **500 K 币**；
3. 回到游戏机前，手持卡带右键屏幕，将卡带装入游戏机。

更换卡带时，游戏机会退回原来的卡带。如果背包已满，退回的物品可能会掉落在玩家附近，请及时拾取。

### 第三步：开始游戏

1. 右键楼梯坐下，也可以执行 `/sit`；
2. 确认卡带已经装入游戏机；
3. 空手右键屏幕即可进入游戏。

一台游戏机最多允许 **2 名玩家**同时游玩。第一位加入的玩家控制 1P，第二位加入的玩家控制 2P；离开座位即可退出操作。

## 启用游戏声音

街机声音通过 Plasmo Voice 的空间音频播放。客户端安装最新版 **Plasmo Voice** 模组并成功连接语音服务后，即可在游戏机附近听到声音。

- 默认声音范围为游戏机附近 16 格，实际范围以服务器配置为准；
- 未安装或未连接 Plasmo Voice 时仍可游玩，但不会播放游戏音频；
- 多人围观时，附近且已连接语音服务的玩家也能听到声音。

## 游戏操作

| Minecraft 操作 | 对应的 NES 按键或功能 |
| --- | --- |
| 移动方向 | 方向键 |
| 跳跃 | A 键 |
| 交换主手与副手 | B 键 |
| 左键屏幕 | Select 键 |
| 右键屏幕 | Start 键 |
| 同时按“跳跃”和“右键屏幕” | 重置游戏 |
| 同时按“跳跃”和“左键屏幕” | 保存游戏 |

## 保存与读取进度

同时按下“跳跃”和“左键屏幕”后，插件会为当前游戏创建一份个人存档。

执行 `/bnes saves` 可以打开存档菜单：

- 左键存档：把存档下载为物品；
- 右键存档：删除该存档；
- 手持存档物品右键运行同一款游戏的游戏机：读取进度。

存档只能读取到对应的游戏中。如果提示 ROM 不匹配，请先装入创建该存档时使用的卡带。

## 无法正常游玩时

- **屏幕没有画面：**确认地图属于同一实例并按正确顺序摆放，必要时重新获取地图；
- **右键后无法操作：**玩家必须先坐在插件支持的座位或矿车上，再右键街机屏幕；
- **卡带无法读取：**请使用卡带菜单中获得的有效卡带，并确认手持卡带右键的是街机地图；
- **没有声音：**确认客户端 Plasmo Voice 已更新并连接成功，同时不要离游戏机太远。

街机功能基于 [BNes-Fork](https://github.com/Aruvelut-123/BNes-Fork) 实现，以上说明依据服务器当前使用的项目版本整理。
