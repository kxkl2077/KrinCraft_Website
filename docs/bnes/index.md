# 🎮 街机使用指南

Stalir 的街机功能可以在游戏内运行 NES 游戏。购买并安装游戏机后，你可以插入卡带游玩超级玛丽、坦克大战等经典游戏。

## 创建游戏机

执行 `/bnes create <实例名>` 创建一台游戏机，费用为 **1000 K 币**。实例名由你自行设置，后续管理时会用到，请妥善记住。

## 安装与游玩

### 第一步：安装游戏机

1. 执行创建指令后，背包中会获得 4 张地图；
2. 在墙面上放置 4 个物品展示框，并按下图排列；

![四格游戏机的安装示意图](/images/bnes.png)

3. 将 4 张地图分别放入对应的展示框；
4. 在屏幕前放置 2 个楼梯作为座位。

### 第二步：购买游戏卡带

1. 执行 `/bnes menu` 打开卡带菜单；
2. 选择想玩的游戏，每张卡带需要 **500 K 币**；
3. 回到游戏机前，手持卡带右键屏幕，将卡带装入游戏机。

### 第三步：开始游戏

1. 右键楼梯坐下，也可以执行 `/sit`；
2. 确认卡带已经装入游戏机；
3. 空手右键屏幕即可进入游戏。

## 启用游戏声音

客户端安装最新版 **Plasmo Voice** 模组后，可以听到街机游戏的声音。未安装时仍可游玩，但不会播放游戏音频。

## 游戏操作

| Minecraft 操作 | 对应的 NES 按键或功能 |
| --- | --- |
| 移动方向 | 方向键 |
| 跳跃 | A 键 |
| 交换主手与副手 | B 键 |
| 左键屏幕 | Select 键 |
| 右键屏幕 | Start 键 |
| 同时按“跳跃”和“右键屏幕” | 重置游戏 |
| 同时按“跳跃”和“左键屏幕” | 保存游戏 |
