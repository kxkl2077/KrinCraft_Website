# 新模组服领地系统

在新模组服中，玩家可以使用领地定点器保护自己的基地。放置定点器后，系统会自动建立以定点器为中心的保护区域；未获得信任的玩家不能在区域内破坏、放置或操作受保护的内容。

::: tip 配方入口
需要制作领地定点器、升级套件、增强方块或显形护目镜时，请查看 [领地物品配方与功能](./goml-recipes)。该页面也说明了每件物品的用途和使用方法。
:::

## 创建领地

1. 制作一个“临时领地定点器”。
2. 在希望保护的位置放下定点器，领地会立即建立。
3. 如果新领地与其他领地重叠，或者位置位于服务器禁止圈地的区域，定点器将无法放置。
4. 领地主人可以破坏自己的定点器来移除领地。

不同定点器的默认保护半径如下。实际数值可由服务器管理员调整，请以游戏内物品提示为准。

| 定点器 | 默认半径 |
| --- | ---: |
| 临时领地定点器 | 10 格 |
| 强化领地定点器 | 25 格 |
| 闪亮领地定点器 | 50 格 |
| 水晶领地定点器 | 75 格 |
| 翡翠领地定点器 | 125 格 |
| 枯萎领地定点器 | 200 格 |

## 查看领地边界

制作“（领地）显形护目镜”，并将它放在以下任意位置：

- 头部装备栏；
- 主手；
- 副手。

装备后即可看到领地边界，选址或升级前建议先确认周围是否有其他领地。

## 管理领地

空手右键领地定点器即可打开管理界面。

- 在“受信任的玩家”中添加或移除成员；
- 在“锚定升级”中查看当前连接的领地增强；
- 领地主人和受信任成员可以在领地内正常建造，其他玩家仍受保护规则限制。

也可以在目标领地内使用下列指令：

| 指令 | 作用 |
| --- | --- |
| `/goml help` | 查看 GOML 指令帮助 |
| `/goml trust <玩家>` | 信任一名玩家 |
| `/goml untrust <玩家>` | 取消信任一名玩家 |
| `/goml addowner <玩家>` | 添加一名共同所有者 |
| `/goml list` | 打开自己可访问的领地列表 |
| `/goml escape` | 被困在无权修改的领地时传送到领地外 |

::: warning 共同所有者
共同所有者拥有比普通信任成员更高的管理权限。只应把可信任的玩家添加为共同所有者。
:::

## 升级领地

领地有两种升级方式：

- 按照配方，用当前定点器直接合成下一级定点器，再重新放置；
- 制作对应的升级套件，手持套件右键当前定点器，在原位置完成升级。

使用升级套件会保留原领地信息。升级后的范围如果与其他领地重叠，升级将被拒绝，套件不会生效。

升级顺序为：

`临时 → 强化 → 闪亮 → 水晶 → 翡翠 → 枯萎`

## 使用领地增强

领地增强必须贴着领地定点器放置，也可以继续贴着已经连接到该定点器的增强方块放置。每块领地只能连接一个同类型增强。带有设置项的增强可由领地主人右键打开设置界面。

| 领地增强 | 效果 |
| --- | --- |
| 末影绑定器 | 阻止领地内的末影人瞬移 |
| 村庄核心 | 保护领地内的村民免受敌对生物伤害 |
| 迎宾者 | 玩家进入领地时显示自定义消息 |
| 天使光环 | 给予领地内玩家生命恢复 |
| 枯萎封印 | 防止玩家获得凋零效果 |
| 力场 | 将符合设置条件的玩家推出领地 |
| 天堂之翼 | 允许领地内飞行 |
| 湖神之恩 | 给予领地内玩家水下呼吸和海豚的恩惠 |
| 混沌领域 | 给予领地内玩家力量效果 |
| PVP 竞技场 | 控制领地内是否允许玩家互相攻击 |
| 爆炸控制器 | 控制领地内的爆炸保护 |

::: info
服务器管理员可以关闭部分增强或调整领地半径，因此游戏内实际效果可能与默认值不同。
:::

新模组服的领地系统基于 [GOML 项目](https://github.com/Aruvelut-123/get-off-my-lawn-reserved) 实现，本文依据服务器所用版本编写。
