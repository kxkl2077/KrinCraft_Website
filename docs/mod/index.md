# 模组服介绍

模组服是基于Create+整合包二次修改而成的，由slouheo编写的任务书，Kxkl和Baymaxawa共同维护服务端的一个以机械动力为主题的模组服务器

通过KrinCraft 群组进行连接，当玩家使用模组服的客户端进服时，KrinCraft会自动将玩家跳转到模组服，以免主大厅不认识模组服客户端而拒绝连接

# 关于客户端更新

模组服的客户端内置一个更新小程序，每次启动自动连接KrinCraft的更新服务器，匹配版本号，若低于更新服务器版本号，自动下载更新包进行更新Mod，资源包等操作
