# 旧模组服介绍

旧模组服是基于 Create+ 整合包二次修改而成的，由 slouheo 编写任务书，Kxkl 和 Baymaxawa 共同维护服务端，是一个以机械动力为主题的模组服务器。

旧模组服通过 KrinCraft 群组进行连接。当玩家使用旧模组服客户端进入服务器时，Stalir 会自动将玩家跳转到旧模组服，避免主大厅无法识别模组服客户端而拒绝连接。

## 关于客户端更新

旧模组服客户端内置更新程序。每次启动时，程序会自动连接 Stalir 更新服务器并核对版本号；客户端版本较低时，会自动下载更新包，更新 Mod、资源包等内容。
