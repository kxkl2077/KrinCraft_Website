# 💰 货币与箱子商店

K 币是 Stalir 的服务器货币，可用于购买物品、街机卡带和部分服务器功能。1 服主城设有多种箱子商店，主要分为向玩家出售物品和向玩家收购物品两类。

::: tip 2 服商店
2 服商店带有完整的操作提示，按照游戏内指引操作即可。
:::

## 查询余额

| 指令 | 说明 |
| --- | --- |
| `/money` | 查看自己的 K 币余额 |
| `/baltop` | 查看本服玩家余额排行 |

## 从商店购买物品

1. 左键点击出售物品的箱子商店牌；
2. 按提示输入要购买的数量；
3. 余额充足时，系统会自动扣除 K 币并把物品放入背包；
4. 余额不足或背包空间不够时，请调整后重试。

## 向商店出售物品

1. 左键点击收购物品的箱子商店牌；
2. 按提示输入要出售的数量；
3. 背包中有足够的对应物品时，系统会自动收走物品并发放 K 币；
4. 物品数量不足时，交易不会完成。

::: warning 确认商店类型
操作前请查看牌子上的物品、单价和“出售 / 收购”信息，避免买卖方向或数量错误。
:::
