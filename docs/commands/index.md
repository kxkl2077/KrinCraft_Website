# 🗨️ 常用指令

这里整理了 Stalir 常用的玩家指令。尖括号中的内容需要替换为实际信息，例如 `/tpa <玩家名>` 应填写为对方的游戏名。

## 正版账号快捷登录

拥有 Minecraft 正版账号的玩家，可以在服务器大厅连续执行两次 `/prem` 开启正版验证。验证成功后，再次进入服务器时无需输入密码。

::: warning 开启前请确认
非正版账号不要开启此功能。开启后，该角色名将只能通过正版验证进入；如需解除，请联系管理员处理。
:::

## 服务器菜单

使用 `/cd` 打开服务器菜单。

## 家与返回

| 指令 | 说明 |
| --- | --- |
| `/sethome` | 将当前位置设置为默认的家，名称为 `home` |
| `/sethome <家的名字>` | 将当前位置设置为指定名称的家 |
| `/home` | 传送到默认的 `home` |
| `/homes` | 打开家的管理界面 |
| `/back` | 返回上一个位置 |

## 玩家传送

| 指令 | 说明 |
| --- | --- |
| `/tpa <玩家名>` | 请求传送至该玩家身边 |
| `/tpahere <玩家名>` | 请求该玩家传送到你的位置 |
| `/rtp` | 随机传送（有冷却时间） |

## 飞行充能

| 指令 | 说明 |
| --- | --- |
| `/flyc` | 开启或关闭飞行充能 |
| `/flightcharge` | 使用 K 币或经验值补充飞行点数 |

飞行时会根据移动距离消耗点数，请及时查看并补充余额。

## 领地系统

原版子服的领地功能请参阅 [Dominion 玩家领地指南](https://dominion.lunadeer.cn/notes/doc/player/dominion/create/)。

::: tip 圈地工具
在 Stalir 圈地时使用的是**箭**，不是指南默认提到的木锄。
:::
