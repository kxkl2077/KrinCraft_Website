# 🐧 账号绑定与群内查询

为减少恶意注册，玩家首次进入子服前需要通过 QQ 群或抖音群绑定社交账号。推荐使用 QQ 群完成自助绑定。

## 绑定账号

1. 进入 Stalir，完成注册或登录后选择 1 服或 2 服；
2. 进入对应子服时，游戏会显示绑定群号和验证码，提示样式如下：

3. 加入提示中的 QQ 群并等待管理员审核；
4. 进群后，按照游戏内提示发送：

`绑定 <你的验证码>`

5. 收到绑定成功的回复后，重新进入对应子服。

::: tip 抖音群绑定
抖音群需要管理员人工处理，等待时间通常更长，建议优先使用 QQ 群自助绑定。
:::

## 查询服务器在线人数

在 QQ 群中发送 `在线人数`，机器人会返回各个子服的在线人数图片。

## 查询自己的服务器信息

在 QQ 群中发送 `我的信息`，机器人会返回你的服务器余额和权限组等信息。

::: warning 注意游戏名大小写
绑定时请确认游戏名和验证码无误，并注意游戏名中的大小写。
:::
